## Methodology

- Suite rate = suite fails / 20 rounds. Solo rate = solo fails / 50 runs.
- Classification: solo rate ≈1 → deterministic; >0 → flaky; 0 with suite fails → interference-only.
- Cause categories read from the test + touched code: timing/async, shared-state, network/port-reuse, filesystem, test-order.
- Dominant cause family: fixed 5s `expect` timeouts vs render latency under parallel load (~60 tests), then async-state races (~12), port-5524 webServer binds (1 file), harness artifacts (4), deterministic stale expectations (2).
