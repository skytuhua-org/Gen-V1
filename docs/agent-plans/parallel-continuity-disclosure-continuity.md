## DESIGN

Retry retains previous answer and current drafts. Obsolete results follow existing action ownership; do not create a second authority protocol.

Keep children in their keyed tree. Resolving visual shell is pointer-inert and aria-hidden after genuine pending, with no cloned input/label/focus target. Measure only actual shell/branch transitions. Dispose observer/animation handlers and retained measurements on completion/cancellation/unmount.

Keyboard/restore follow accepted immediate/retained W3 behavior; accepted pointer/real-source effects consume duration once. Input and authoritative source updates never wait for presentation completion. Shared helper defects are explicit owner handoffs, not a reason to expand this leaf. Rollback reverts only its Disclosure/CSS diff, preserving action/timing repairs.
