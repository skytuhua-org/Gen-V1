# Gen V1 logo and brand assets

[Back to the README](../../../README.md)

The mark is a G made from halftone dots, followed by dotted “enV1” lettering. The approved Electric purple is `#7C4DFF`; the logo is designed for both dark `#09090B` and light `#F6F4FB` backgrounds.

## Usage

- Use the frosted logo at 300px wide or more, and only where SVG filters render.
- Use the flat logo for small sizes, print, or one-color applications.
- Use the dot mark at 48px and above; use the solid G at 32px and below.
- Keep clear space around the logo of at least half the G’s height.

Do not recolor beyond Electric purple, white, or black; add solid letters beside the dotted G; or stretch the artwork. Preserve its proportions.

The lettering is derived from the Unbounded typeface (SIL Open Font License 1.1), rendered to dots. No font file ships with these assets.

Upload `gen-v1-social-preview.png` manually in GitHub **Settings → Social preview**.
