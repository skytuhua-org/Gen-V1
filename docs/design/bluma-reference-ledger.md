## Provenance contract

- **Observed preview** means the public Bluma preview behavior recorded in the accepted 2026-11-25 parent research; **licensed source inspected** means authorized readable files and terms were inspected; **verified Gen runtime** means the Gen-V1 implementation was exercised at a recorded SHA. No row has licensed Bluma source inspected.
- Public previews and free/paid labels do not establish redistribution permission. The public terms and MCP descriptions inspected in the parent plan did not grant this session catalog source or redistribution rights, so every row remains `independent adaptation` unless later authorized source acquisition supplies hashes, license text, author/source, dependencies and retained notices.
- No Bluma login, purchase, MCP installation, copied minified page internals, new runtime dependency, external telemetry, production gallery or timeless catalog count is used. The catalog changed during inspection; component identity and observation date are the durable facts.
- Evidence remains synthetic and separate from #1811's integrated 29-interface/24-live-trial acceptance. Clips required by downstream evidence workers are 1920x1080, 30 fps, H.264, real interaction speed, with no titles, labels, simulated cursor or other overlays in the footage. Captions, provenance, SHAs, settings and hashes belong in manifests.
- Narrow 390x844/390x300 and zoom 100/125/150% checks are additional layout evidence; browser zoom does not prove native display DPI. Full/Reduced/Off motion evidence must remain truthful and no real operation may be delayed to make animation visible.

## Evidence input contract

Evidence workers consume the ledger commit and return one `EvidenceRow` per pattern:

```ts
{pattern, baselineSha, candidateSha, fixtureSha, environment, settings, steps, checks, files:[{url,sha256,bytes,format}], disposition, remainingGate}
```

Every baseline/candidate pair uses identical source data, viewport, policy, speed and steps. A pair may differ from another pattern's pair; that does not satisfy #1811's separate all-on-one-SHA gate. Missing candidate or evidence facts stay `PENDING` with the required artifact named; they are never success claims.
